MetalWolf

MetalWolf is an independent macOS port of the Wolfenstein 3D engine source
code. It is not affiliated with, endorsed by or sponsored by id Software or
ZeniMax Media. Wolfenstein is a trademark of ZeniMax Media; the name is used
here only to say which game this port runs.

Game data

  No game data is included: no maps, graphics, sounds or music from
  Wolfenstein 3D. The startup picture compiled into the original source
  release is not included either. You need your own copy of Wolfenstein 3D
  version 1.4 (GT/Activision or Apogee), or the shareware episode.

  The sounds of the gore effects are synthesized by the program at run time.
